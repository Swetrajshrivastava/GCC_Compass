# GCC Compass AI context

This folder captures the product intent, current implementation, operating rules, design conventions, and next steps for GCC Compass. Read these notes before making changes so the prototype's evidence limits and product scope stay clear.

## Suggested reading order

- Starting work: `Memory.md` and `Task.md`
- Product or feature work: `PRD.md`, `Architecture.md`, and `Rules.md`
- UI work: `design.md`
- Finishing a work session: update `Task.md` and record durable decisions in `Memory.md`

These documents describe the current prototype; they are not a substitute for checking the code and data. Update them when the implementation or product direction changes.
